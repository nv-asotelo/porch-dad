About the comparison

The Live VLM WebUI preset matches its camera request, frame interval, default prompt, token limit and temperature. Actual camera resolution and FPS depend on your device. This interface counts browser video frames and streams tokens; upstream counts frames after WebRTC and returns complete answers. JPEG encoders also differ. Compare complete-answer time using the same source and model; this is not an identical transport benchmark.
