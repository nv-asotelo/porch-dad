About the comparison

Lightweight restores the first demo settings. The Live VLM WebUI capture preset matches its camera request, frame interval, JPEG quality and temperature. Switching capture presets preserves your prompt, output token limit and advanced settings. For its default prompt and answer cap, choose Scene Description and set the output limit to 512. Actual camera resolution and FPS depend on your device. This interface counts browser video frames and streams tokens; upstream counts frames after WebRTC and returns complete answers. Reachy Mini arrives as an image stream, which exposes no frame count, so with that preset it is sampled on a 6-second timer while its bridge is live: the time 30 frames take at the bridge's nominal 5 FPS. Input image tokens and top-p are separate model settings above. Latency and Average use server inference timing only, excluding JPEG encoding and decoding, network transfer and queueing. Compare the same images, prompts and settings across backends; browser timing diagnostics are not used for scoring.
